# Suporte

- Dúvidas de uso e propostas de melhoria: use as Discussions, quando habilitadas.
- Defeitos reproduzíveis: abra uma issue com dados sintéticos.
- Vulnerabilidades: siga `SECURITY.md` e não publique detalhes exploráveis.

O projeto comunitário não oferece suporte oficial do e-SUS APS ou do Ministério da Saúde.
