## 2. Causa do `blocked_by_source` no Runtime

### Diagnóstico

O container Docker usa o usuário `esus_leitura` para conectar ao DB `esus_restore_20260424` na porta 5432. Este usuário **não tem GRANT SELECT** nas tabelas C2/C3 (`tb_fat_cidadao_pec`, `tb_fat_atendimento_individual`, etc.).

A função `checkTable` em `common.ts` executa:
```sql
SELECT 1 FROM information_schema.tables WHERE table_name = $1
SELECT COUNT(*)::int FROM <table>
```

Sem GRANT, a segunda query lança `permission denied for table <table>`, que `checkTable` captura como `freshnessStatus = "ERROR"`. O hard block check:
```typescript
return state?.freshnessStatus === "MISSING" || state?.freshnessStatus === "ERROR";
```
...dispara, bloqueando o cálculo.

### Evidência

```
Container env:
  PEC_DB_USER=esus_leitura
  PEC_DB_PORT=5432
  PEC_DB_NAME=esus_restore_20260424
  NODE_ENV=production
  ALLOW_DEV_SESSION_LOGIN=false

API response:
  status: blocked_by_source
  warnings: ["HARD_BLOCKED: tabelas obrigatorias indisponiveis"]
```

### Separação de Responsabilidades

| Camada | Status |
|--------|--------|
| Código fonte C2/C3 | **SOURCE_VALIDATED** — validado via tsx direto, porta 5433, usuário `postgres` |
| Runtime tRPC/API | **VALIDATED** — rota, auth, JSON, PII OK |
| DB runtime (esus_leitura) | **BLOCKED_BY_PERMISSION** — GRANT faltando (ação de DBA) |

**Isso não é um bug de código.** É uma pendência de configuração de permissões de banco.

### Correção Necessária (DBA)

```sql
-- No banco esus_restore_20260424, executar como superuser:
GRANT SELECT ON tb_fat_cidadao_pec TO esus_leitura;
GRANT SELECT ON tb_fat_atendimento_individual TO esus_leitura;
GRANT SELECT ON tb_fat_atendimento_odonto TO esus_leitura;
GRANT SELECT ON tb_fat_vacinacao TO esus_leitura;
GRANT SELECT ON tb_fat_visita_domiciliar TO esus_leitura;
GRANT SELECT ON tb_fat_atd_ind_procedimentos TO esus_leitura;
GRANT SELECT ON tb_fat_atd_ind_exames TO esus_leitura;
GRANT SELECT ON tb_dim_cbo TO esus_leitura;
GRANT SELECT ON tb_dim_procedimento TO esus_leitura;
GRANT SELECT ON tb_dim_tempo TO esus_leitura;
GRANT SELECT ON tb_equipe TO esus_leitura;
```
