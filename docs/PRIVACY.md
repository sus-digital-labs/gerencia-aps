# Privacidade

O frontend pode apresentar dados pessoais e dados de saúde quando conectado a uma API autorizada. O responsável pela implantação deve:

- limitar cada resposta ao município, equipe e finalidade do usuário;
- evitar identificadores completos quando não forem necessários;
- registrar acessos e exportações;
- impedir que dados reais entrem em testes, issues ou logs;
- informar ao usuário quando uma ação abrir um serviço externo;
- definir retenção, descarte e resposta a incidentes.

Este repositório não distribui base de dados e não contém credenciais de produção.
