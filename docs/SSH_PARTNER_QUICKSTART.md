# Quickstart SSH - Parceiro

## 1) Instalar config SSH
- Salvar o arquivo `SSH_CONFIG_esus-feedback.conf` como `~/.ssh/config` (ou mesclar ao existente).

## 2) Conectar
- Perfil principal: `ssh esus-feedback-anton`
- Perfil alternativo: `ssh esus-feedback-anton-2222`

## 3) Banco PostgreSQL PEC
- Host: `127.0.0.1`
- Porta: `5433`
- Banco: `esus`
- Usuario DB: `esus_feedback`
- Senha DB: enviada por canal seguro

## 4) Credenciais

- Senha Linux: enviada por canal seguro
