# C1 — Mais acesso à Atenção Primária à Saúde

**Revisão:** 2026-08-26  
**Programa:** Saúde Brasil 360  
**Regra:** `C1@2026.3`  
**Status técnico:** `blocked_by_source`  
**Código de bloqueio:** `C1_BLOCKED_BY_DATA_CONTRACT`

## Fonte e definição

A fonte primária é a Nota Metodológica C1 do Ministério da Saúde [1]. O indicador mede a proporção de atendimentos de demanda programada em relação ao total de atendimentos elegíveis na APS.

```text
percentage = atendimentos_programados / atendimentos_elegiveis * 100
```

A classificação deve vir do modelo de informação oficial ou de dimensão oficial relacionada ao fato. Não inferir o tipo por texto livre, procedimento, consulta genérica ou evidência indireta de acesso.

## Bloqueio atual

O schema auditado de `tb_fat_atendimento_individual` não comprova a existência de uma variável confiável para distinguir demanda programada e espontânea. A presença de `co_dim_tipo_atendimento` ou `tb_dim_tipo_atendimento` em uma documentação não prova que a chave esteja na réplica, que a dimensão esteja carregada, que o code set esteja vigente ou que a cardinalidade seja íntegra.

Os códigos `1`, `2`, `4`, `5` e `6` aparecem em documentos internos como conjunto candidato. Eles só podem ser utilizados depois de confirmação contra a nota metodológica, o guia e-SUS APS, a dimensão carregada e a competência.

A issue P0 está em [c1-data-contract-issue-2026-08-26.md](../13-saude-brasil-360/c1-data-contract-issue-2026-08-26.md). Enquanto permanecer aberta, não publicar percentual substituto.

## Retorno seguro

```json
{
  "indicatorCode": "C1",
  "program": "SAUDE_BRASIL_360",
  "ruleVersion": "C1@2026.3",
  "status": "blocked_by_source",
  "errorCode": "C1_BLOCKED_BY_DATA_CONTRACT",
  "message": "Indicador indisponível: a fonte não comprova a classificação oficial da demanda do atendimento.",
  "safe": true,
  "warnings": [
    "C1_MISSING_OFFICIAL_DEMAND_TYPE",
    "C1_TIPO_ATENDIMENTO_REFERENCE_INCOMPLETE"
  ]
}
```

O retorno bloqueado não deve conter percentual, numerador ou denominador apresentados como resultado válido. A interface deve mostrar indisponibilidade, nunca zero.

## Contrato mínimo para reabertura

| Campo lógico | Requisito |
|---|---|
| Atendimento | Chave estável, data/competência e deduplicação. |
| Território | Equipe e unidade filtráveis. |
| Profissional | Chave e CBO elegível. |
| Pessoa | Chave técnica sem PII no agregado. |
| Tipo de demanda | Código original, descrição oficial e classificação programada/espontânea. |
| Versão | Sistema, modelo de informação e linhagem do registro. |

## Critérios de aceite

- [ ] Chave e dimensão oficiais disponíveis na competência.
- [ ] Cardinalidade validada sem duplicação.
- [ ] Code set confirmado na fonte vigente.
- [ ] Registros sem classificação ficam pendentes ou são descartados com motivo explícito.
- [ ] Consulta reproduzível por competência, equipe e unidade.
- [ ] Reprocessamento idempotente.
- [ ] Versão de origem e modelo registrados.
- [ ] Ausência de dependência produz `blocked_by_source`.
- [ ] Nenhuma PII ou SQL bruto em agregado, log ou exemplo público.

## Evidência histórica

Execuções anteriores com `numerator=679`, `denominator=1713` e `percentage=39.64` são evidências técnicas datadas. Não constituem homologação normativa e não devem ser tratadas como resultado vigente enquanto o contrato permanecer incompleto.
