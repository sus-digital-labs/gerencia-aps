# Código de conduta

Este projeto busca uma colaboração respeitosa, técnica e acolhedora.

São esperados comunicação clara, crítica construtiva, respeito à privacidade, boa-fé e responsabilidade com dados de saúde. Assédio, discriminação, exposição de dados pessoais, intimidação ou ataques pessoais não serão aceitos.

Problemas de conduta devem ser comunicados de forma privada ao mantenedor do repositório. Medidas podem incluir orientação, moderação, remoção de conteúdo ou bloqueio de participação, de acordo com a gravidade.
